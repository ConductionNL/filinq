## Tasks

- [ ] 1. **Route registrations** — add seven new entries to `appinfo/routes.php`: `POST batch/upload`, `POST batch/{batchId}/extract`, `GET batch/{batchId}/status`, `POST batch/{batchId}/anonymize`, `GET batch/{batchId}/report`, `GET anonymization/profiles`, `PUT anonymization/profiles`; place specific routes before any wildcard `{slug}` routes (ADR-003); register a CORS OPTIONS route for each if the app exposes public CORS headers.

- [ ] 2. **`BatchAnonymizationController`** — scaffold `lib/Controller/BatchAnonymizationController.php` with seven thin methods (ADR-003: <10 lines each, routing + validation + response only); inject `BatchAnonymizeService`, `BatchExtractionService`, `BatchReportService`, and `WooProfileService` via constructor with `private readonly`; annotate `upload()`, `extract()`, `status()`, `anonymize()`, `report()`, and `getProfiles()` with `#[NoAdminRequired]`; annotate `updateProfiles()` with `#[AuthorizedAdminSetting(Application::APP_ID)]`; add `@spec openspec/changes/batch-anonymization/tasks.md#task-2` PHPDoc tag on each method and class-level header docblock.

- [ ] 3. **`BatchAnonymizeService` — ICache state management** — create `lib/Service/BatchAnonymizeService.php`; inject `ICache`, `IAppConfig`, `IRootFolder`, `IUserSession`, `LoggerInterface`; implement `createBatch(array $files): array` — validate count against `docudesk_batch_max_files` (default 100), store initial state under key `docudesk_batch_{uuid}` with 2-hour TTL, return batch ID + file stubs; implement `getBatchState(string $batchId): array` — read from ICache, throw `BatchNotFoundException` when missing; implement `updateBatchState(string $batchId, array $state): void` — write back to ICache and extend TTL to 2 hours from now; implement `resolveBatchStatus(array $files): string` — derive `batchStatus` from per-file statuses (`uploading`, `extracting`, `review`, `anonymizing`, `completed`, `error`).

- [ ] 4. **`BatchExtractionService`** — create `lib/Service/BatchExtractionService.php`; inject `BatchAnonymizeService` + OpenRegister lazy-resolved services (pattern from `AnonymizationService` — `getInstalledApps()` check + `container->get()`); implement `extractNext(string $batchId): array` — load batch state, find first file with `status === "uploaded"`, call `TextExtractionService::extractFile()`, call `EntityRelationMapper::findEntitiesForFile()`, update file status to `extracted` with `entityCount`, call `BatchAnonymizeService::updateBatchState()`; on extraction failure set file status to `error` with error message; when no `uploaded` files remain, set batch `batchStatus` to `review`; return per-file result + progress counts; throw `BatchNotFoundException` on missing batch.

- [ ] 5. **`BatchAnonymizeService` — anonymisation orchestration** — implement `anonymizeBatch(string $batchId, array $entities): array` — validate non-empty `entities` (throw `InvalidArgumentException` → HTTP 400); build deduplicated entity-to-UUID map using `random_bytes(16)` (RFC 4122 v4) once before iterating files; for each file with `status === "extracted"`, call `FileService::anonymizeDocument()` with the shared entity map; update file status to `anonymized` with `replacementCount` and `anonymizedFilePath`; skip files with `status === "error"` — collect in `skippedFiles`; set batch `batchStatus` to `completed`; call `updateBatchState()`; return `files` + `skippedFiles` arrays; NO PII in log messages (ADR-005).

- [ ] 6. **`BatchReportService`** — create `lib/Service/BatchReportService.php`; implement `generateReport(string $batchId): string` — load batch state, throw `BatchNotCompletedException` (→ HTTP 409) if not `completed`; build CSV string with header row `fileName,originalFileId,anonymizedFileId,entityCount,replacementCount,status,timestamp` and one data row per file; entity values MUST NOT appear in any column (GDPR Recital 26); return raw CSV string; the controller sets `Content-Type: text/csv` and `Content-Disposition: attachment; filename="anonymization-report-{batchId}.csv"`.

- [ ] 7. **`WooProfileService`** — create `lib/Service/WooProfileService.php`; inject `IAppConfig`; implement `getProfile(): array` — read `docudesk_woo_entity_profiles` from IAppConfig, fall back to hardcoded default `{"woo-default": {"name": "WOO Standaard", "anonymize": ["PERSON", "BSN", "PHONE", "EMAIL", "IBAN", "ADDRESS"], "keep": ["ORGANIZATION", "LOCATION", "DATE"]}}` if key is absent or invalid JSON; implement `saveProfile(array $profile): void` — JSON-encode and persist to IAppConfig; admin check is enforced at the controller annotation layer (`#[AuthorizedAdminSetting]`), not duplicated in the service.

- [ ] 8. **Batch upload validation in controller** — in `BatchAnonymizationController::upload()`: extract uploaded files from the multipart request; validate count before passing to service; return HTTP 400 with static error message "Batch size exceeds maximum of N files" when exceeded; return HTTP 401 when `IUserSession::getUser()` is null; on success return HTTP 200 JSON with `batchId`, `fileCount`, and `files` array; follow ADR-005: use `$user->getUID()` for storage path, NEVER trust a client-supplied user ID; NEVER return `$e->getMessage()` in HTTP responses — log server-side and return a static error string.

- [ ] 9. **Admin settings integration** — surface `docudesk_batch_max_files` in the admin settings UI as a numeric input (min: 1, max: 1000, default: 100); surface the WOO profile `anonymize` and `keep` category lists as tag/chip editors; wire the save handler to `PUT /api/anonymization/profiles`; display a read-only default profile fallback when no custom profile is saved; coordinate with frontend on `SettingsController` extension.

- [ ] 10. **`BatchNotFoundException` and `BatchNotCompletedException`** — create `lib/Exception/BatchNotFoundException.php` and `lib/Exception/BatchNotCompletedException.php` as minimal `\RuntimeException` subclasses; used internally so the controller can map them to HTTP 404 and HTTP 409 respectively without exposing internal error messages to clients.

- [ ] 11. **Unit tests — `BatchAnonymizeService`** — `tests/unit/Service/BatchAnonymizeServiceTest.php`: (a) `createBatch()` returns a valid UUID batchId and stores correct ICache structure; (b) count at limit is accepted; count above limit throws; (c) `getBatchState()` throws `BatchNotFoundException` on cache miss; (d) `resolveBatchStatus()` returns correct status for all-uploaded, mixed, all-extracted, all-anonymized, and partial-error file sets; (e) `anonymizeBatch()` builds a single entity map and applies it to all extracted files; (f) same entity value → same UUID across two files; (g) empty entities array throws; (h) error-status files appear in `skippedFiles`.

- [ ] 12. **Unit tests — `BatchExtractionService`** — `tests/unit/Service/BatchExtractionServiceTest.php`: (a) `extractNext()` selects the lowest-index `uploaded` file; (b) successful extraction sets status to `extracted` with correct `entityCount`; (c) extraction failure sets status to `error` with message, batch continues; (d) no `uploaded` files → sets `batchStatus` to `review`; (e) unknown batchId → `BatchNotFoundException`.

- [ ] 13. **Unit tests — `BatchReportService`** — `tests/unit/Service/BatchReportServiceTest.php`: (a) completed batch → valid CSV with correct header; (b) entity values not present in any column; (c) `anonymizedFileId` empty for error-status rows; (d) non-completed batch → `BatchNotCompletedException`.

- [ ] 14. **Unit tests — `WooProfileService`** — `tests/unit/Service/WooProfileServiceTest.php`: (a) absent IAppConfig key → hardcoded default returned; (b) invalid JSON in IAppConfig → hardcoded default returned; (c) valid saved profile → returned as-is; (d) `saveProfile()` JSON-encodes and persists to IAppConfig.

- [ ] 15. **Integration tests — Newman** — add to the Newman collection: (a) upload 5 PDFs → assert `batchId` + `fileCount: 5` + all statuses `uploaded`; (b) call extract in loop until `batchStatus === "review"` → assert each call returns `filesExtracted`/`totalFiles`; (c) call `GET /status` → assert correct `progressPercent`; (d) call anonymise with entity list → assert `batchStatus: "completed"` and consistent pseudonyms across files (spot-check via report); (e) call `GET /report` → assert CSV headers and row count; (f) call `GET /report` on non-completed batch → assert HTTP 409; (g) call `GET /profiles` → assert default profile shape; (h) admin `PUT /profiles` with modified list → assert saved; (i) non-admin `PUT /profiles` → assert HTTP 403; (j) upload 101 files → assert HTTP 400.
