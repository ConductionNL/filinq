## 1. Signing

- [x] 1.1 Add a delegation period to the mandate in `lib/Controller/SigningFolderController.php` and a screen to declare and withdraw one in `src/views/signing/` (REQ-SCR-003). Verify: PHPUnit refuses a delegate after the end date.
  - Built: `SigningDelegationService` keeps delegations (signer, colleague, first and last day, `<app>/<schema>` types) in app config; the signer declares and withdraws them over `GET/POST api/signing/delegations` and `DELETE api/signing/delegations/{id}`, on a Delegated signing section of the signing folder (`src/views/signing/SigningDelegations.vue`). Pinned by `SigningDelegationTest`.
- [x] 1.2 Add a phone code provider behind the signer-authentication seam in `lib/Service/Signing/` (REQ-SCR-004). Verify: PHPUnit for a right, a wrong and an expired code.
  - Built: `PhoneCodeProvider` (`phone-code`, registered in `SignerAuthProviderFactory`) sends a six-digit code to the `phoneNumber` on the signer record through `PhoneCodeSenderInterface`, keeps only its hash for five minutes, accepts it once, voids it after five wrong tries, and records `phone-code` as the means without the code or the number; a new `code` challenge type. Pinned by `PhoneCodeProviderContractTest` (the provider contract plus a right, a wrong and an expired code). Not built: a text message gateway (an instance binds `PhoneCodeSenderInterface`; without one the provider refuses to start) and the code entry field in the step-up screen.
