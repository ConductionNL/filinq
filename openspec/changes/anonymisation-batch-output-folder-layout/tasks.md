## Tasks

- [x] 1. **Output layout helper** — implemented as `lib/Service/Conversion/OutputLayoutResolver.php`. `resolveBatchDestination()` accepts the source folder path + base name + extension and returns the canonical destination. Trailing `_anonymized` is stripped via `LEGACY_SUFFIX_REGEX`. Constructor injects `IAppConfig` + `LoggerInterface`. `getSubfolderName()` reads `filinq.anonymisation.output_subfolder_name` (default `anonymised`), validates against `/^[a-z0-9_-]+$/`, and falls back to the default with a warning when invalid. `isLegacyAnonymizedOutput()` exposes the same discrimination for source-discovery filters.
- [x] 2. **Admin settings UI for subfolder name**: the field "Subfolder for anonymised copies" in `src/views/settings/Settings.vue`, checked as you type by `src/services/outputSubfolder.js` (`outputSubfolder.spec.js`). The server is the authority: `SettingsService::updateSettings()` refuses an empty name or any character outside `/^[a-z0-9_-]+$/` before writing anything, naming each character in the error the settings endpoint returns (`SettingsServiceTest::testInvalidOutputSubfolderNameIsRefusedAndNothingIsWritten`). The save no longer reports success on a non-OK response.
- [x] 3. **BatchAnonymizeService integration**: `BatchAnonymizeService::runBatch()` hands each anonymised file to `lib/Service/Conversion/OutputLayoutMover.php`, which moves OR's `<base>_anonymized.<ext>` into `<source>/<subfolder>/<clean>.<ext>` in one `move()`, creating the subfolder and replacing a previous run's file of the same name. The folder flow (`FolderExtractionJob`) now uses the same mover instead of its own copy.
- [x] 4. **Move-failure handling**: a failed move or a node that cannot be found keeps the legacy path, attaches `warning.code` `MOVE_FAILED`, logs a warning, and the file still counts as anonymised (`OutputLayoutMoverTest`, `BatchAnonymizeServiceOutputLayoutTest::testMoveFailurePreservesFileAtLegacyPathWithWarning`).
- [x] 5. **Path-recording update**: the batch entry now carries `anonymizedFilePath`, set to the subfolder path after the move (it carried no path before).
- [x] 6. **Source-discovery filter**: the batch-upload surface takes uploaded files, so it has no discovery to filter; the folder flow filters `_anonymized` sources in `FolderFileEnumerator` and `FolderExtractionJob`. A re-anonymised legacy file loses every trailing suffix (`OutputLayoutResolver::LEGACY_SUFFIX_REGEX` is now `/(_anonymized)+$/`), so `foo_anonymized.pdf` lands as `anonymised/foo.pdf`.
- [x] 7. **Single-file regression guard** — `tests/unit/Service/AnonymizationServiceSingleFileRegressionTest.php` enforces at the source level that `lib/Service/AnonymizationService.php` does NOT import or reference `OutputLayoutResolver`, `resolveBatchDestination`, or `isLegacyAnonymizedOutput`. Positive control asserts `FolderBatchService.php` exists so a missing file cannot silently turn the guard into a no-op. Regression now caught at unit-test time rather than waiting for the integration PR.
- [x] 8. **Grondslagen summary destination handoff**: `GrondslagenPdfWriter::saveDossierSummary()` writes `<dossier>/<subfolder>/grondslagen.pdf`, creating the subfolder when missing (`GrondslagenPdfWriterDossierSummaryTest`).
- [x] 9. **Helper unit tests** — `tests/unit/Service/Conversion/OutputLayoutResolverTest.php` covers all four corners (clean filename unchanged, trailing `_anonymized` stripped, mid-name `_anonymized` preserved, invalid configured subfolder falls back with warning) plus the source-discovery `isLegacyAnonymizedOutput` discriminator and trailing-slash path normalisation.
- [x] 10. **BatchAnonymizeService unit tests**: `tests/unit/Service/BatchAnonymizeServiceOutputLayoutTest.php` now runs through the real mover and resolver and asserts the persisted batch entry (path, warning, no move without a file id), replacing assertions that only counted processed files. `tests/unit/Service/Conversion/OutputLayoutMoverTest.php` covers the mover itself.
