Product: Filinq Categorie: Documentbeheer, publicatie-instemming & GDPR-compliance Licentie: EUPL-1.2 (vrije open source) Leverancier: Conduction B.V. Platform: Nextcloud + Open Register (self-hosted / on-premise / cloud)
