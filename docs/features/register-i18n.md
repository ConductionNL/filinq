# Register Content Internationalization (Planned)

## Overview

Multi-language support for Filinq's register objects, allowing users to view and manage document templates in their preferred language. Built on OpenRegister's register-i18n foundation.

## Status: Proposed

This feature is planned but not yet implemented.

## Planned Features

- Template title and description in multiple languages (nl/en minimum)
- Field label and help text translation
- Language resolution based on user's Nextcloud locale
- Fallback to default language when translation unavailable
- Generated documents are single-language artifacts (not translatable)
